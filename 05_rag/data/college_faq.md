# AGENT-M Workshop FAQ

AGENT-M is a two-day hands-on artificial intelligence workshop.

## Venue
Sree Chitra Thirunal College of Engineering (SCTCE), Thiruvananthapuram.

## Dates
October 3 and 4, 2026.

## Timing
Sessions run from 9:30 AM to 4:30 PM on both days.

## What to bring
Participants should bring a laptop with Wi-Fi, a modern browser, Python 3.12 or newer,
and a charger. Installing uv before the workshop is recommended.

## Topics
The workshop covers generative AI, prompt engineering, structured output,
tool calling, RAG, AI agents, agent teams, multimodal AI, vision, voice pipelines,
and a simple Python user interface.

## Programming stack
The demos use Python, uv, Agno, OpenAI and Streamlit.
No Node.js is required.

## Final activity
Teams modify the Campus AI Buddy into a specialist agent for a college-related problem.
